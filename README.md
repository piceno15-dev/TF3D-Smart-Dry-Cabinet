# TriFusion 3D – Smart Dry Cabinet

Repositorio oficial del producto **TF3D-SDC-01**.

## Estado
- Versión: `v0.3.1`
- Sprint: `3.1 – CAD mecánico inicial`
- Material: melamina blanca de 18 mm
- Dimensiones exteriores: 800 × 1000 × 500 mm
- Control previsto: Raspberry Pi Pico W

## Abrir el ensamble
1. Instala OpenSCAD.
2. Abre `cad/assembly/TF3D-SDC-01_Assembly.scad`.
3. Pulsa `F5` para previsualizar o `F6` para renderizar.

## Aviso
Esta revisión es editable y sirve para validar geometría. Antes de fabricar deben cerrarse puerta, perforaciones, uniones, ductos, herrajes y capacidad real.
