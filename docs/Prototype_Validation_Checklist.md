# Checklist del primer prototipo

## Dimensional
- [ ] Exterior 800 × 1000 × 500 mm.
- [ ] Gabinete escuadrado; diferencia de diagonales ≤ 3 mm.
- [ ] Puerta abre sin interferencias.
- [ ] Los 16 carretes entran y pueden retirarse.

## Estructural
- [ ] Prueba de cada par de soportes con 2.5 kg durante 24 h.
- [ ] Prueba conjunta con 16 carretes.
- [ ] Sin grietas, flexión permanente ni aflojamiento.
- [ ] Fondo sin deformación visible.

## Sellado
- [ ] Canto PVC sin zonas expuestas.
- [ ] Cordón de silicón continuo.
- [ ] Burlete continuo.
- [ ] Prueba de papel uniforme.
- [ ] Recuperación de humedad se medirá en sprint de pruebas.

## Mantenimiento
- [ ] Se reemplaza un soporte sin desmontar el gabinete.
- [ ] Se retira una varilla sin retirar las bobinas contiguas.
- [ ] Se accede al compartimento técnico.
- [ ] La puerta puede desmontarse.

## Seguridad
- [ ] Bordes sin filo.
- [ ] Acrílico asegurado.
- [ ] Gabinete estable y nivelado.
- [ ] Ningún elemento eléctrico energizado durante esta prueba mecánica.
